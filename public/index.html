采集环境信息

↓ 下载 collect_environment.py

将文件放到源码总目录，在训练容器内或训练机器上，先激活实际训练使用的 Python 环境，再选择对应命令

Conda / Docker
python collect_environment.py \
  --mode pip --root "$PWD" \
  --output environment.txt
uv 环境
python collect_environment.py \
  --mode uv --root "$PWD" \
  --output environment.txt

输出包含 CANN、PTA、当前目录及直属子目录的源码 commit，以及包版本列表。已有 environment.txt 时，请更换输出文件名
